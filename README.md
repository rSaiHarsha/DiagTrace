# DiagTrace
Automotive vehicle diagnostic data analysis application

## Quick Start

To run the entire application (Backend API + Frontend UI):

```bash
python run.py
```

This single command will:
1. Automatically detect the local Python virtual environment (`venv`).
2. Start the Uvicorn server serving FastAPI REST APIs and static frontend files at `http://127.0.0.1:8000`.
3. Automatically launch your default web browser to `http://127.0.0.1:8000`.
